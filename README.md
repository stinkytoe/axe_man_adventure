# Axe Man Adventure!

## Description

This is a small demo used to showcase the features and capabilities of [Shieldtank](https://github.com/stinkytoe/shieldtank), a [Bevy](https://bevyengine.org) plugin which provides a framework for making games with the [LDtk](https://ldtk.io) editor!

Play now on itch.io: [Axe Man Adventure](https://stinkytoe.itch.io/axe-man-adventure)

# About the Game:

The vile Green Lancer is taking over the Island of Thieves! But our hero, The Axe Man, is here to save the day with his mighty cleave! But be careful, the Lancer has a dangerous reach!

# Development notes

This is a simple game I am using to help steer development of the [Shieldtank](https://github.com/stinkytoe/shieldtank) plugin. The game is short and simple, but showcases some basic features that could be use to develop a proper traditional top-down adventure game or RPG.

## The World

The world consists of two levels: `Island_of_Thieves` and `Peninsula_of_Pain`. When in the `Playing` state, the world labeled `axe_man_adventure.ldtk#world:World` is loaded which contains these levels, and their associated layers and entities.
